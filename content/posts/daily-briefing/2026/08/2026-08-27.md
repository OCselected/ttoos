**【L2 · 治理结构变化】** 核心观察：**vLLM 尚无正式的治理文件**（仓库无 GOVERNANCE.md / MAINTAINERS.md，GitHub API 返回 404）。这意味着 76 名新贡献者的涌入是在**"无正式治理框架"**的状态下发生的——这是一个制度经济学意义上的关键信号。用威廉姆森四层框架分析：vLLM 当前的"治理"发生在 L4（资源配置，靠 GitHub merge 权限的 de facto 分配），尚未建立 L3 治理机制（SIG/TC/RFC 流程）。当社区从 270 人扩张到 400 人（按当前速度约 3-4 个月），**L4 的 de facto 治理将无法承载，L3 治理机制的建立将成为"必然的制度跃迁"**。这是今日 Project Pulse 最核心的判断：**vLLM 正处于"从项目到制度"的临界点**。

**【L3 · 新人加入与社区活力】** 76 名新贡献者在两周内进入，且贡献覆盖 Kimi-K3、DeepSeek V4、AMD ROCm、Rust 前端等多条技术线——**新人不是"来修 bug 的"，是"来扩展基础设施边界的"**。这是社区健康的积极信号，但也意味着**治理框架必须同步进化**，否则 L3 新人会被 L2 的缺失挡在核心之外——这是开源社区"新人衰减曲线"的经典陷阱（Shah 2006 的核心发现）。

**开源之道判断**：vLLM 的"无治理文件 + 高新人流入"组合，是**"制度真空中的自组织活力"**的典型样本。它可能在 6-12 个月内完成从 L4 到 L3 的制度跃迁（建立 SIG 或 TC），也可能因治理框架建立滞后而出现贡献者衰减。**这是"慢聚漫奏"（求兴）路径，不是"效率求生"（大分流 2.0）——**vLLM 的扩张不是行政规划的，是技术需求驱动的自发秩序。适兕的 Copyleft 是互惠外化的理论在此可桥接：**vLLM 没有用许可证外化互惠，而是用"多模型多硬件的公共基础设施化"外化了互惠**——贡献者通过贡献特定模型/硬件的优化，换取自身模型/硬件在框架中的原生支持。这是一种比 copyleft 更深层的制度外化——**技术生态本身就是治理机制**。

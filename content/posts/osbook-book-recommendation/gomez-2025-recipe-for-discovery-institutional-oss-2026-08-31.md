# 2026-08-31  「开源之道」·论文略读：Recipe for Discovery — A Pipeline for Institutional Open Source Activity — Gomez et al.

## 论文信息

| 字段 | 内容 |
|------|------|
| **标题** | Recipe for Discovery: A Pipeline for Institutional Open Source Activity |
| **作者** | Juanita Gomez, Emily Lovell, Stephanie Lieggi, Alvaro A. Cardenas, James Davis |
| **年份** | 2025（v2 2026-02） |
| **平台** | [arXiv:2506.18359](https://arxiv.org/abs/2506.18359) (cs.SE) |
| **案例** | 加州大学十所分校（UC system） |

## 一句话推荐

Gomez 等人没有提出新的理论框架，而是提出了一条**发现管道**——把"看不见"的学术开源从"个例报道"变成"可测量的制度对象"。这是新制度经济学里最朴素也最锋利的一条：**未被测量的东西，无法进入任何治理议程**。

## 内容概要

论文提出一个端到端管道用于系统性地识别分布式学术系统中的开源项目：从 GitHub REST API 拉取数据、提取元数据、预测机构归属与项目类型（开发工具 / 教育材料 / 网站 / 文档），并以加州大学十所分校为案例识别出**超过 20 万个仓库**。核心经验发现只有两条：

- **超过 70% 的仓库缺少明确许可证**；
- **EDU（教育类）与 DEV（开发类）项目各占约 42%**——学术机构几乎一半的开源产出是"知识生产本身"而非"软件生产"，此前没有任何公开数据支撑这个判断。

高 Star 项目更倾向于采用社区标准，但**整体而言学术开源项目的社区实践成熟度仍然偏低**——"缺失许可证"与"有限社区参与"是两种最突出的模式。这是学术机构开源贡献**第一次被系统性量化观察**——此前这类工作依赖人肉调研与零散 case study。

## 为什么值得读

- **方法论价值大于具体发现**：论文的贡献不是"UC 有 20 万仓库"，而是"**如何把学术开源从不可见变成可见**"。这条发现管道对任何想建立 OSPO 的大学、任何想做制度分析的研究者，都是一份可复用的工具规范。
- **量化了 Coase 意义上的产权未界定**：70% 缺许可证不是"疏忽"，而是 Coase 意义上**产权未界定的知识公地**——贡献者与使用者的权利义务没有契约前提。学术开源普遍"先发布、后考虑合规"，公地的边界规则（Ostrom 八原则之"边界明确"）整体缺位。
- **揭示了"第三部门"的制度空白地带**：大学既非市场也非国家（Hansmann 意义上的第三部门），其开源活动既不受市场价格机制约束、也不受行政科层指令驱动，处于 **Acemoglu 包容性/汲取性制度分析未覆盖的区域**——没有成熟的治理范式，而是被"附属子系统的默认设置"（GitHub 公有仓库 + 个人名义发布）所决定。
- **为 OSPO 提供数据驱动决策工具**：这条管道不是学术研究的一次性产出，它可以作为大学 OSPO 的日常运营工具——识别被忽视的开源资产与合规风险，是制度化的**基础设施层**工作。
- **补上大分流 2.0 的跨国对照**：适兕 2026-08-24 判断 MirrorZ 由 27 家高校 + 中科院维护是"开源基础设施被教育化"的证据；Gomez 用数据证明**学术机构开源贡献的制度空白是普遍结构，而非中国特色**——只是填补路径不同：中国走"行政教育化"（MirrorZ 包镜像），美国大学走"自发去中心化"（个人/实验室级发布、许可证缺失）。

## 为什么对开源社区如此重要？

Gomez 等人做的事情，从制度经济学的视角看，恰好落在**North 信息成本**这条最深的地基上。Douglass North 反复强调：制度变迁不是观念的博弈，而是**信息成本下降**触发制度重排。当"机构开源贡献难以追踪"，任何针对学术开源的政策、任何关于大学 OSPO 的讨论，都停留在轶事层面——因为它们无法回答最基本的"到底有多少、分布在哪儿、缺什么"。这条发现管道把答案从"不知道"变成"有数据"，制度化的第一步就已经完成。

对开源社区而言，这条管道回答了一个被长期忽略的问题：**"学术开源"到底是一个制度议题还是不是一个制度议题？** 在论文之前，这个问题几乎无从回答——没有数据、没有基线、没有可比性。20 万个仓库、70% 缺许可证、EDU 占 42%——这些数字让"学术开源"从"某个实验室的浪漫主义"变成"一个可被制度讨论的对象"。**制度分析的边界，就是数据可见性的边界。**

再往深一层：论文揭示的"缺许可证 + 有限社区参与"这两种模式，恰好对应 Ostrom 八条设计原则中**"边界明确"与"监督机制"**两条的系统性缺位——不是某个大学疏忽，是整个"第三部门"在开源制度上处于**未覆盖状态**。Williamson L1→L4 顺序在这里出现了一次跳层：**L1 嵌入性（大学文化）直接跳过 L3 治理机制、映射到 L4 资源配置**——没有 L2 制度环境约束、没有 L3 治理机制设计，只有 L4 上"GitHub 公有仓库 + 个人名义发布"这个默认设置替大学做了决定。**这是学术开源最隐蔽也最要紧的制度问题**——它不体现在任何一份政策文件里，它体现在"没有政策"的地方。

大分流 2.0 视角下，这条管道给出的跨国证据尤其值得玩味。适兕判断开源在中国不能靠市场存活，所以被转移到了**非市场空间**（教育系统）里存活——MirrorZ 是典型证据。Gomez 证明**美国大学也把开源放进了非市场空间**——但那里的表现不是"教育化"，而是"去中心化 + 许可证缺失"。同一结构空白（学术机构开源）在两个制度环境下被填成了完全不同的形状：中国是**行政教育化**（可测量的、被纳入体系但制度弹性有限），美国是**自发表散化**（不可测量、许可证缺位但技术实践活跃）。这两种形态都不是"更优"，是**制度环境的产物**。

对中国的制度观察者，这篇论文是一面冷静的镜子。它把中国讨论"高校如何开源"从"能不能建 MirrorZ"这种**行政议题**，转回**制度议题**——大学开源的根本问题不是"要不要建镜像"，是"有没有产权界定、有没有边界规则、有没有测量能力"。**没有测量就没有治理，没有治理就没有制度**。这是 Gomez 论文里最锋利的一刀，也是大分流 2.0 最容易被忽略的一层。

## 关联阅读

- **North《Institutions, Institutional Change and Economic Performance》(1990)** — Gomez 的方法论价值直接落在 North 的**信息成本**命题上：未被测量的活动无法进入制度议程。
- **Ostrom《Governing the Commons》(1990)** — 70% 缺许可证对应 Ostrom 八原则中"边界明确"与"监督机制"两条的系统性缺位，是公地治理理论在学术场景的反面案例。
- **Coase《The Nature of the Firm》(1937) 与产权定理** — 70% 缺许可证是 Coase 意义上的**产权未界定**，学术开源最基础的权利义务契约前提整体缺位。
- **O'Mahony & Ferraro《The Emergence of Governance in an Open Source Community》(2007)** — Gomez 提供的是"学术开源的可见性"，O'Mahony & Ferraro 提供的是"成熟社区的治理涌现"——两者构成学术开源从"看不见"到"治理涌现"的经验链条。
- **Gehring《The Institutionalization of Open Source》(2006)** — Gehring 用 NIE 分析开源如何成为制度；Gomez 则提供了 NIE 分析最上游的**测量基础设施**——没有这条管道，制度分析无从下手。
- **适兕 · MirrorZ 分析（2026-08-24）** — 中国行政教育化路径与美国自发去中心化路径的跨国对照，构成大分流 2.0 关于"学术开源填补路径"的核心案例。

## 延伸思考

如果 Gomez 今天重写这篇论文，她大概不会把 AI Agent 贡献排除在"仓库贡献者"之外。**AI Agent 的引入会让"机构归属预测"这个核心方法面临根本挑战**——当一个仓库的贡献者一半是 human、一半是 agent，"这个仓库属于 UC Berkeley"这个命题本身就需要被重新定义。Agent 贡献的规模越大，"机构开源"的定义权就越模糊——这是 Williamson 治理结构在 AI 时代的又一次 L3→L4 传导问题。

更根本的一个追问：Gomez 的方法论把"发现"作为起点，但制度经济学的分析告诉我们，**测量本身就是一种制度选择**。当一条发现管道定义了"什么算机构开源"（GitHub 上的、UC 十所分校的、以机构域命名的），那些**不在此定义内的开源活动就被制度性地隐去了**。中国的高校开源如果走 MirrorZ 路径，其数据完全落不到 Gomez 的管道里——不是因为中国没有学术开源，而是**测量框架本身带有制度偏置**。**这是新制度经济学最锋利的一层洞见：任何测量都携带制度选择，任何可见性都伴随不可见性。**

再往深处追问：Gomez 揭示的"70% 缺许可证"，究竟是**制度缺位**还是**制度未覆盖**？前者意味着需要新建制度，后者意味着现有制度不适用。对第三部门而言，这是二者的复合——**市场制度不适用于大学、行政制度不适用于大学，第三部门需要的是一种"自我立法"的能力**。但第三部门的天然弱点正是自我立法能力弱——它缺乏市场的价格反馈、缺乏国家的行政强制力。**这是开源在第三部门面临的最深制度难题**：不是设计更好的规则，而是设计出**能让第三部门自己产生规则的环境**。Gomez 的管道只是把问题摆上桌，答案仍需下一代研究回答。

Gomez 等人的论文，最终指向适兕反复强调的一个判断：**生态是结果，不是手段**。学术开源生态不是"构建"出来的（许可证策略 + OSPO + 政策文件），是**制度环境让大学能够自发形成开源生态**的自然产物。任何试图用行政、基金会、许可证来"构建生态"的努力，都必然在 Gomez 揭示的制度空白地带遇到同一堵墙——**你不能命令一所大学成为开源者，你只能设计出让它愿意开源、能够开源、可持续开源的制度环境**。这是开源之为思想的力量，也是开源之为制度的脆弱。

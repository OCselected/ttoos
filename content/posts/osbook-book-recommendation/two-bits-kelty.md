## 书籍简介

在开源研究的学术谱系中，绝大多数著作聚焦于经济学（Lerner & Tirole 的激励分析）、政治学（Weber 的制度分析）或公共治理（Ostrom 的集体行动框架）。Kelty 的《Two Bits》开辟了一条完全不同的路径——**文化人类学**。

Kelty 在 1990 年代末至 2000 年代初深入自由/开源软件社区，进行了长时间的田野调查。他不是问「开源为什么成功？」或「开发者为何免费贡献？」，而是问了一个更根本的人类学问题：**这群人通过制造软件，在制造一种什么样的世界？**

答案凝结在他提出的核心概念——**递归公共性（Recursive Publics）** 之中。

## 核心概念：递归公共性

所谓递归公共性，是指一个群体不仅通过讨论来协商公共事务，而且他们赖以讨论的技术基础设施本身——邮件列表、版本控制系统、Bug 跟踪器、许可证文本——也是这场讨论的对象和产物。换言之，Geeks 在写代码的同时，也在撰写社会契约。

这一概念的深刻之处在于：

1. **基础设施即政治**：自由软件社区不是「先有规则，后有技术」，而是规则与技术同步演化。GPL 许可证不仅是一份法律文件，它本身就是一场关于「什么构成自由」的持续争论的物质化形态。

2. **公共性的递归定义**：开源的「公共性」不是固定的，而是递归的——每一次技术变革（从 CVS 到 Git、从邮件列表到 GitHub Issues），都意味着公共性被重新协商。社区成员既是公共基础设施的使用者，也是它的创造者和修改者。

3. **Geeks 作为道德主体**：Kelty 展示了自由软件程序员如何通过许可证辩论（GPL vs BSD）、标准化过程（IETF）、基础设施治理（Debian 社会契约）来参与政治生活——以一种不同于传统公民政治的方式。

## 为什么值得读

- **填补了开源研究的人类学空白**：如果说 Weber 告诉你开源的政治经济学、Ostrom 告诉你开源的制度逻辑，那么 Kelty 告诉你开源的意义世界——这群人究竟怎样理解自己在做的事情。

- **对「开源文化」研究的奠基性贡献**：与 Coleman 的 《Coding Freedom》 构成了开源人类学的双璧。Coleman 聚焦于自由软件运动中的道德和政治维度，Kelty 则更关注技术基础设施如何塑造公共性。两者对读，可以形成完整的开源文化图景。

- **在 AI 时代重新被激活的概念**：当 GitHub Copilot 的代码生成引发「什么构成合理使用」的激烈争论，当 AI Agent 开始向开源仓库提交 PR，「递归公共性」的概念获得了全新的解释力——这些争论本质上是在递归地重新协商「谁可以参与、如何参与、基础设施应当如何运作」。

## 延伸思考

1. 「递归公共性」概念能否解释今天的开源生态？当 GitHub 成为一个平台垄断基础设施（而非社区自建的基础设施），公共性是否在被平台化？Kelty 的框架可以帮助我们诊断平台时代的开源公共性危机。

2. 中国开源社区是否存在「递归公共性」？如果技术基础设施（Gitee、微信、钉钉）不是社区自建而是平台提供的，公共性的递归特征是否被切断？

3. 在 AI Agent 时代，「递归公共性」面临新的挑战——当贡献者不再是人类而是 Agent，公共性的边界在哪里？谁来协商 Agent 参与的技术基础设施？

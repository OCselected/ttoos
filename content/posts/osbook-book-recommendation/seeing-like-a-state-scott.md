# Seeing Like a State: How Certain Schemes to Improve the Human Condition Have Failed（国家的视角）

**作者**：James C. Scott（詹姆斯·C·斯科特）
**出版年份**：1998
**领域**：政治科学、人类学

## 在信任思想谱系中的位置

斯科特是信任思想谱系的「历史实证」——为「信任不能用行政命令来生产」提供了最宏大、最惨痛的历史证据。全书探讨一个核心命题：为什么国家用行政命令推行的「极端现代主义」（high modernism）社会工程，总是以失败告终？答案在于：国家「看不到」（cannot see）那些地方性的、非正式的、基于信任的协作机制。

「极端现代主义的承载者往往只看到他们强加的正式秩序，却看不到那些被他们摧毁的、非正式的、基于信任的秩序。」

斯科特的经典案例——德国的「科学林业」：行政命令清除了原始森林，种植了整齐划一的单树种「科学森林」，最终因生态多样性灭绝导致大面积虫害死亡（Waldsterben）。

## 对开源的启示

斯科特的分析框架直接映射到开源治理的核心矛盾：「可读性」（legibility）。国家和企业试图将开源社区「变得可读」——标准化贡献流程、KPI 考核、指标仪表盘。但开源社区中最有价值的部分恰恰是「不可读的」：非正式的维护者网络、IRC/微信群中的非正式讨论、基于长期声誉积累的信任关系。当行政命令试图将这些「不可读」的信任机制替换为「可读」的管理流程时，实质是在摧毁开源生态的生命力。
